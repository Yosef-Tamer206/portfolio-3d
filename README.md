# Yousef Tamer | 3D Portfolio

Interactive 3D developer portfolio, built with React, TypeScript and Vite.

**Live demo:** https://yosef-tamer206.github.io/portfolio-3d/

## What's inside

- Extruded 3D hero with orbiting tech chips around a circular portrait
- Seven projects with screenshots, live links and source links
- Rotating skills orbit around a "Front-End" sphere
- About section with contact links (GitHub, LinkedIn, email)
- Responsive down to mobile widths

`index.html` at the repo root is the self-contained production build (all JS, CSS
and images inlined) that GitHub Pages serves. Full source available on request.

## Projects featured

- Mal3abak (prototype) — Arabic football pitch booking
- Kanban Task Manager (prototype) — drag-and-drop task board
- Mudabbir — financial dashboard
- GameArena — games discovery website
- EliteHomes — real-estate landing experience
- NutriPlan — nutrition planning
- What's For Dinner — meal inspiration
