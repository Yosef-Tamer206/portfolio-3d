# Yousef Tamer | Portfolio

Dark, calm front-end developer portfolio. Live at https://yosef-tamer206.github.io/portfolio-3d/

## What's inside
- Hero with a bold headline, accent colors and quick links
- About, skills and seven selected projects with screenshots, live links and source links
- Events section: photographic documentation of attended tech events, sourced from his own LinkedIn posts
- Contact section with direct links

## Tech
- Plain HTML, CSS and JavaScript. No frameworks, no build step, no 3D.
- Images are stored as base64 data URLs in the `imgdataNN.js` bundles and swapped into `img` tags at runtime by a small resolver in `index.html` (GitHub's web upload flow was unavailable, so binary assets ship as JS).
